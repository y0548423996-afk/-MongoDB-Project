חלק ג' – CRUD
1.	find עם לפחות שלושה תנאים
*סוג הופעה *קטגוריה שירה*מתחת 80 שקל*
db.events.find({
type:"הופעה",
 category: "שירה",
  price:{$lt:80}
  })
2.	Find אחד שבודק נתון של התאריך
index✌️✌️✌️✌️
כשעושים חיפוש ארוע לפי תאריך החיפוש יהיה מהיר יותר
וכן הקלה בשליפת הארועים הנמצאים על התאריך המסוים
db.events.createIndex({eventDate:1})
זה השאילתה השניה עכשיו זה רץ עפ האינדקס
db.events.explain().find({
  eventDate: { $eq: new Date("2025-07-10") }
})
**איזה הופעות מתקיימות אחרי התאריך 01/06**
db.events.find({
  eventDate: { $gt: new Date("2025-06-01")}
})
3.	Find אחד שבודק נתון של המערך
*שם כל מי שקנה כרטיס על מספר בין שלוים לארבעים*
db.users.find(
{tickets:/^tick3/},
{fullName:1, _id:0}
)
4.	עדכון document בודד לפי תנאי – העדכון צריך להיות כזה שישפיע על שאילתות ה find כך שנוכל לראות הבדל בתוצאת השאילתא לפני ואחרי.
*עושות את זה על שאלה 1 מורידותא את המחיר עושות מבצע  *
db.events.updateOne(
{id:1},
{ $set:{price:75}}
)
5.	עדכון מספר documents – כנ"ל לגבי השפעה על התוצאות של ה find.
*נעשה שכל הופעה שהיא אחרי ה01/06 נעלה לו את המחיר ב10 שקל ואז בשאלהה אחד ישתנה *
db.events.updateMany(
{eventDate: { $gt: new Date("2025-06-01") }},
{$inc:{price:10}}
)
6.	מחיקת document – כנ"ל לגבי השפעה על התוצאות של ה find.
*בשביל זה  נעשה חיפוש נוסף כדי שנוכל לראות את ההבדל*

db.organizers.find(
  {$and: [
      {"address.city":{$in:["ירושלים", "אלעד"]}},
      {name:{$regex:"הפקות$"}}
  ]},
  {name:1, contactPerson:1, "address.city":1 , _id:0}
)
*מחיקה*
db.organizers.deleteOne({
"address.city":"ירושלים"
})
*עכשיו יש ארוע שהארגון שנמחק מארגן אז נשנה*
db.events.updateOne(
{id:4},
{$set:{organizerId:6}}
)
